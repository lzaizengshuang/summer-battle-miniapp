先确认：你的账号类型对不对

⚠️ 重要提醒

本项目是普通小程序，不是小游戏。如果你之前注册的是「小游戏」账号，导入时会报错 dist/game.json 找不到。小游戏账号改不成普通小程序，只能重新注册。

✅ 普通小程序
后台左侧菜单：首页、管理、开发、功能、推广、统计
服务类目有：教育、工具、生活服务等
❌ 小游戏账号
后台左侧菜单：首页、小游戏、管理、开发、功能
服务类目只有：休闲游戏、动作游戏等

如果不确定，看后台左侧有没有「小游戏」三个字。有的话就是小游戏账号，请直接看步骤 1 重新注册。

1

注册普通小程序账号

  1. 电脑浏览器打开 微信公众平台
  2. 点击页面右上角 立即注册
  3. 选择 小程序（不要选小游戏）
  4. 填写一个未注册过微信公众平台的邮箱，设置密码，完成邮箱验证
  5. 选择主体类型。个人最简单但部分功能受限；企业/个体工商户功能最全但需营业执照；其他按实际选
  6. 填写主体信息，提交审核。个人通常很快通过
💡 注意

一个邮箱只能注册一个小程序账号。如果你之前注册的是小游戏，必须换一个邮箱。

2

获取 AppID

审核通过后，登录公众平台后台：

  1. 左侧菜单点击 开发 → 开发管理
  2. 点击顶部 开发设置
  3. 找到 AppID(小程序ID)，形如 wx1234567890abcdef
  4. 复制这串字符，后面导入项目时要填
你会看到的页面：开发设置页，有 AppID、AppSecret、服务器域名、扫普通链接二维码打开小程序 等模块。我们只需要 AppID。
3

下载并安装微信开发者工具

  1. 打开 微信开发者工具下载页
  2. 根据你的系统下载稳定版（Windows 或 macOS）
  3. 下载后双击安装，一直点下一步即可
  4. 安装完成后打开，用微信扫码登录
4

下载项目源码

  1. 打开 GitHub 仓库：https://github.com/lzaizengshuang/summer-battle-miniapp
  2. 点击页面中间偏右的绿色按钮 <> Code
  3. 选择 Download ZIP
  4. 下载完成后，在电脑里解压，得到一个 summer-battle-miniapp-main 文件夹
📁 解压后文件夹里有什么

主要文件夹：src/（前端代码）、cloudfunctions/（后端云函数）、dist/（编译好的小程序文件）。

5

导入项目到微信开发者工具

  1. 打开微信开发者工具
  2. 点击 导入项目（如果没有，点左上角菜单 项目 → 导入项目）
  3. 在弹窗里，选择解压后的 summer-battle-miniapp-main 文件夹
  4. AppID 处粘贴步骤 2 复制的 AppID
  5. 后端服务 选择 微信云开发
  6. 点击 导入
导入成功后会看到：左侧文件树有 cloudfunctions、config、src 等文件夹；中间是小程序模拟器；右侧是调试器。如果显示首页内容，说明导入成功。
🚨 如果报错 dist/game.json 找不到

说明你用的是小游戏账号，必须重新注册普通小程序（回看步骤 0 和步骤 1）。

6

开通微信云开发

本项目数据存在微信云开发里，必须先开通。

  1. 在开发者工具顶部工具栏，点击 云开发 按钮
  2. 按提示开通，选择一个离你近的节点
  3. 开通后进入云开发控制台
  4. 点击顶部 设置 → 环境设置，复制 环境 ID（形如 xxx-xxx）
📝 可选：配置环境 ID

如果项目没有自动绑定环境，打开 src/utils/cloud.ts，把环境 ID 填进去：

wx.cloud.init({
  env: '你的环境ID',
  traceUser: true,
});
7

初始化数据库

需要创建 4 个数据集合。

  1. 在云开发控制台，点击左侧 数据库
  2. 点击 添加集合 或 +
  3. 依次创建 4 个集合：childProfiles、plans、records、progress
  4. 每个集合创建后，点击 权限设置
  5. 选择 仅创建者可读写（保护孩子数据）
🤖 另一种方式：用云函数初始化

部署完 init-db 云函数后（见步骤 8），在开发者工具控制台执行：

wx.cloud.callFunction({ name: 'init-db' }).then(console.log)

返回 success: true 即表示集合和索引已创建。

8

部署云函数

本项目有 18 个云函数，需要逐个上传到云端。

  1. 在开发者工具左侧文件树，展开 cloudfunctions/
  2. 右键点击第一个云函数目录，例如 init-db
  3. 选择 创建并部署：云端安装依赖（如果没有，选 上传并部署：云端安装依赖）
  4. 等待提示部署成功
  5. 对其余每个云函数目录重复上述操作
必须部署的云函数
init-db、getOrCreateDefaultChildProfile、createChildProfile、listChildProfiles、switchDefaultChildProfile、updateChildProfile、createPlan、getCurrentPlan、updatePlan、getDaySchedule
继续部署
startBattle、toggleTask、reportDay、getProgress、getRankInfo、getRecords、backupData、restoreData
💡 检查是否成功

进入云开发控制台 → 云函数，应该能看到 18 个函数列表。如果某个失败，右键重新部署。

9

真机预览测试

  1. 在开发者工具顶部点击 预览
  2. 会生成一个二维码
  3. 用微信扫码，在手机上打开小程序
  4. 按流程测试：首次进入创建向导 → 选王子/公主主题 → 设假期起止日期 → 添加任务 → 完成任务并汇报 → 查看等级、勋章、记录 → 长按等级徽章 3 秒进家长后台
🔧 如果测试报错

打开手机上的 vConsole（右上角 ⋮ 菜单里开启），把红色错误截图发给开发者。

10

上传代码

  1. 确认预览没问题后，点击开发者工具顶部 上传
  2. 填写版本号，例如 1.0.0
  3. 填写项目备注，例如 首次发布
  4. 点击 上传
上传成功后：登录公众平台 → 管理 → 版本管理 → 在 开发版本 里能看到刚上传的版本。
11

提交审核

  1. 在公众平台 → 版本管理 → 找到开发版本
  2. 点击右侧 提交审核
  3. 按提示填写：功能页面选首页；服务类目选教育或工具相关；测试账号一般不需要；备注可写「儿童假期作业打卡工具，支持任务管理、等级勋章」
  4. 勾选《微信小程序平台审核规则》
  5. 点击 提交审核
⏱ 审核时间

通常 1-7 个工作日。审核结果会发通知到管理员微信。

12

发布上线

  1. 审核通过后，登录公众平台 → 版本管理
  2. 在 审核版本 中点击 发布
  3. 选择发布方式：全量发布（所有用户立即看到）或灰度发布（先给部分用户，逐步放开）
  4. 点击确认发布
🎉 上线后

用户可以在微信搜索小程序名称，或扫描小程序码访问。后续更新重复步骤 9-12。

?

常见问题

导入报错 dist/game.json
账号是小游戏账号，需重新注册普通小程序。
云函数调用失败
检查是否全部部署，以及环境 ID 是否正确。
数据库找不到集合
手动创建 4 个集合，或调用 init-db 云函数。
主题切换后刷新恢复
确保 updateChildProfile 云函数已部署。
审核被驳回
按审核意见调整类目或补充材料。
真机白屏
更新微信到最新版，或在开发者工具开启调试。
